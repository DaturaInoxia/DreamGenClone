# Debug 008 — Character Stat State Texts & Resistance Band Not Injected

**Created:** 2026-07-17

## Report

Slot 13 (Behavioral Frames) produces no output — no behavioral frames, no stat state texts, no resistance band directive appear in any prompt. The spec mandates Slot 13 carries all character behavioral guidance (FR-019: "NPC agency lives here, not as a separate slot").

Three text types should flow through Slot 13 but none reach it:
1. `CharacterBehavioralFrames` — generated by `ScenarioGuidanceContextFactory`
2. `CharacterStatStateTexts` — generated from `CharacterStatTextCatalog` (e.g. "she is noticeably engaged and responds eagerly")
3. Wife resistance band directive — from `StatResistanceProfileService` (e.g. "Untouchable — the affair scenario is functionally off the table")

## Analysis

`ScenarioGuidanceContextFactory` is injected as `_scenarioGuidanceContextFactory` in `RolePlayContinuationService` but **never called** in `BuildPromptViaBuilderAsync`. The `ScenarioGuidanceContext` (which contains all three text types) is never generated for the new prompt builder path.

Legacy path (`RolePlayAssistantPrompts.AppendScenarioGuidance`) calls the factory and injects these as HARD CONSTRAINT blocks. The new prompt builder path does not.

`context.CharacterBehavioralFrames` in `PromptBuildContext` is always null → `BehavioralFramesSlot.ShouldWrite()` returns false → slot never fires.

## Plan

1. **Call `_scenarioGuidanceContextFactory.CreateAsync()`** in `BuildPromptViaBuilderAsync` to populate the `ScenarioGuidanceContext`
2. **Add `CharacterStatStateTexts` to `PromptBuildContext`** — `IReadOnlyDictionary<string, string>?`
3. **Populate `CharacterBehavioralFrames`** in context from the factory output
4. **Update `BehavioralFramesSlot`** to inject both behavioral frames AND stat state texts per character, plus the resistance band directive for the Wife

**Files:** `PromptBuildContext.cs`, `RolePlayContinuationService.cs`, `BehavioralFramesSlot.cs`
**Blast radius:** Within frozen 17-slot contract — only enriches existing Slot 13

## Resolution

Implemented across three files:

1. **`PromptBuildContext.cs`** — Added `CharacterStatStateTexts` field (`IReadOnlyDictionary<string, string>?`)
2. **`RolePlayContinuationService.cs`** — `BuildPromptViaBuilderAsync` now calls `_scenarioGuidanceContextFactory.CreateAsync()` to populate both `CharacterBehavioralFrames` and `CharacterStatStateTexts` in the context. Averages computed from `AdaptiveState.CharacterSnapshots`. Falls back to 50 when no snapshots exist.
3. **`BehavioralFramesSlot.cs`** — `ShouldWrite` fires if either behavioral frames OR stat state texts exist. `WriteAsync` now appends both sections: behavioral frames (character tendency) and stat state texts (character current state). Both follow the same actor-filtered pattern (own first, then present, then non-present).
