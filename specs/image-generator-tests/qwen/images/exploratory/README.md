# Unscored Interaction Explorations

These four images are preserved because they informed the decision to use manual staged edits for complex multi-person interaction geometry:

- `interaction-one-pass.png`
- `interaction-stage1-pose.png`
- `interaction-stage1-close-pose.png`
- `interaction-stage2-man-hands-head.png`

They are **not** part of the controlled six-of-six proof, carry no accepted quality score, and should not be used to claim interaction-editing capability. The original exploration did not retain a complete prompt and execution ledger for these individual files, so they are intentionally not replayable. The exact controlled prompts that are available are preserved in the parent `manifest.json`.
