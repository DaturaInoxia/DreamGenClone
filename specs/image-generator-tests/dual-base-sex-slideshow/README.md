# Dual-Base Sex Slideshow Test Suite

This is the production-grade sex slideshow harness that supports arbitrary locations with proper character identity conditioning via dual T2I bases.

## Why This Exists

The original `sex-slideshow` harness used a single base image for all 20 steps. This works for simple studio backgrounds but fails when Becky needs to face away from the camera (step 12+) — Qwen edits risk identity drift.

**Solution:** Generate TWO T2I bases upfront with identical location conditioning but different character orientations:
- **Base A**: Dean (`profr`) + Becky (`profl`) facing each other → steps 1–11
- **Base B**: Dean (`profr`) + Becky (`profr`) facing away → steps 12–20

Each step edits from its respective base via `-FromBase` mode. No frame is derived from another edited frame.

## Files

| File | Purpose |
|---|---|
| `run-dual-base-slideshow.ps1` | The 20-step harness; selects Base A or Base B per step |

## Prerequisites

Before running, you need:
1. **Location references** generated by `dual-base-location/make-location-reference.ps1`
2. **Dual bases** generated by `dual-base-location/make-dual-base.ps1`

Example paths:
```
specs/image-generator-tests/dual-base-location/refs/locref-bedroom-....png
specs/image-generator-tests/dual-base-location/bases/bedroom/bedroom-baseA-....png
specs/image-generator-tests/dual-base-location/bases/bedroom/bedroom-baseB-....png
```

## Usage

### Bedroom Location

```powershell
$baseA = 'specs/image-generator-tests/dual-base-location/bases/bedroom/bedroom-baseA-bedroom_00001_.png'
$baseB = 'specs/image-generator-tests/dual-base-location/bases/bedroom/bedroom-baseB-bedroom_00002_.png'

& specs/image-generator-tests/dual-base-sex-slideshow/run-dual-base-slideshow.ps1 `
    -Prefix bedroom `
    -BaseA $baseA `
    -BaseB $baseB `
    -RunId 20260914-01-bedroom-full `
    -Checkpoint 'Qwen-Rapid-AIO-NSFW-v23.safetensors' `
    -LoraName 'QwenEdit2511_AllIncludedGay_v2.safetensors' -LoraStrength 0.8 `
    -ComfyUiUrl 'https://comfy.kenacwood.net'
```
