# B-111 Frozen Golden Set

This directory contains the FROZEN golden set for the B-111 phase gates. The scorer in `tools/consistency-scoring` consumes `manifest.json`.

Changing this set invalidates all prior baselines and requires a recorded decision. Reference IMAGES are NOT part of P0; they are produced by P2 Reference Bootstrap. P0 ships only the prompt, seed, and description specification.

Future rendered files use the naming convention `<promptId>__<seed>.png`.
