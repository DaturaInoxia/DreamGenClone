# B-111 Shared UI Components

This directory contains the nine buildable design specs for the shared components defined by `ui-contract.md` section 2. They are design specs consumed by P1+; no code has been created yet.

- [EditIterateWorkbench](EditIterateWorkbench.md) - describe, compile, run, compare, and iterate.
- [CandidateGrid](CandidateGrid.md) - curate candidates through comparison decisions.
- [RunTray](RunTray.md) - monitor runs and control jobs.
- [ResolvedRenderBadge](ResolvedRenderBadge.md) - expose resolved render submission settings.
- [ReferencePicker](ReferencePicker.md) - choose an approved versioned reference.
- [StrategySelector](StrategySelector.md) - choose a qualified identity strategy.
- [ScorecardPanel](ScorecardPanel.md) - show the three-metric render scorecard.
- [FrozenTextBlockEditor](FrozenTextBlockEditor.md) - edit validated invariant reference text.
- [LineageTree](LineageTree.md) - inspect and branch attempt history.

These specs preserve the B-111 UI contract, including U1-U9, the section 3 screen inventory, and G8's design-spec-before-code boundary.
